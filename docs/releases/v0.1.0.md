The first release of Dune Bot.

Dune Bot is an assistant for your own computer. Ask it something from a small bar, or hold a key and
talk. A coding agent does the work on your computer, and the answer appears in a small card by your
pointer and is read aloud. Anything risky asks you first.

## What it does

- **Ask by typing or by voice.** macOS: tap ⌥⌘ for the bar, hold ⌥⌘ to talk. Windows and Linux:
  Ctrl+Alt+Space, and hold the mic button to talk.
- **Answers at once, then works.** It says what it's doing ("Sure, checking the weather where you
  are."), keeps working, then reads you the answer.
- **Uses the agent you already have:** Claude Code, Codex, Cursor, OpenCode, Grok or Antigravity.
- **Asks before anything risky.** Installs, deleting files, changing git or system settings show a
  card first. Activity lists every step it took.
- **Sees and locates only when asked.** It looks at your screen or finds where you are only when a
  question needs it.
- **Learns from mistakes.** When a step fails, "Teach a fix" saves what it should do next time.

## Download

| System | File |
|---|---|
| macOS, Apple Silicon | `Dunebot-0.1.0-mac-arm64.zip` (signed and notarized by Apple) |
| Windows, x64 | `Dunebot-0.1.0-windows-x64.zip` |
| Linux, x64 | `Dunebot-0.1.0-linux-x64.tar.gz` |

Each file has a `.sha256` checksum next to it.

## Install

- **macOS:** unzip, move `Dunebot.app` to Applications, open it. It lives in the menu bar. A setup
  window asks once for the microphone, notifications and your folders.
- **Windows:** unzip anywhere and run `Dunebot.exe`. The app isn't code-signed yet, so SmartScreen may
  warn you: click **More info**, then **Run anyway**. It lives in the tray.
- **Linux:** `tar -xzf Dunebot-0.1.0-linux-x64.tar.gz`, then run `Dunebot-linux-x64/dunebot`.

## You need

- One coding agent installed and signed in: Claude Code, Codex, Cursor, OpenCode, Grok or
  Antigravity. codemax, which runs them, is included.
- For voice: the speech model downloads during setup. Answers are read with your system's voice, or
  with Sarvam or Deepgram if you add a key in Permissions › Voice.

## Known limits

- No automatic updates yet: get new versions from this page.
- No Intel Mac build yet.
- Linux: the card's pointer following hasn't been tried on a real Linux desktop yet, and on Wayland
  the card stays in one place.
